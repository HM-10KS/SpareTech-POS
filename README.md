# موجة البرمجة — منظومة قطع غيار السيارات والشاحنات

تطبيق سطح مكتب لويندوز بواجهة عربية واتجاه RTL، مع قاعدة بيانات SQLite محلية. يعمل دون الحاجة إلى إنترنت بعد تجهيز بيئة التطوير وتثبيت التطبيق.

## المزايا الموجودة
- لوحة تحكم وإحصاءات للمبيعات والمخزون والديون.
- إدارة الأصناف: باركود، تصنيف، نوع المركبة، الماركة، أسعار الشراء والبيع، الكمية، حد التنبيه، وموقع التخزين.
- فواتير مبيعات مع أكثر من صنف، وطرق دفع منها نقدي، ادفع لي، موبي كاش، تحويل مصرفي، وان باي، وآجل.
- البيع النقدي والآجل والجزئي، مع اسم الزبون ورقم الهاتف.
- خصم تلقائي من المخزون والتحقق من الكمية المتاحة.
- إدارة الزبائن والمصروفات والتقارير وتصدير تقرير CSV.
- إنشاء نسخة احتياطية واستعادة قاعدة البيانات.
- بيانات تجريبية أولية للأصناف عند أول تشغيل.

## التشغيل
1. ثبّت Node.js إصدار LTS على ويندوز إن لم يكن مثبتًا.
2. افتح PowerShell داخل مجلد المشروع.
3. نفّذ:
   ```powershell
   npm install
   npm start
   ```
4. عند نجاح التشغيل ستفتح نافذة التطبيق. تُحفظ قاعدة البيانات داخل مجلد بيانات التطبيق الخاص بالمستخدم، وليس بجانب ملفات المشروع.

## بناء ملف تثبيت لويندوز
بعد اتصال إنترنت ناجح لتنزيل أداة البناء:
```powershell
npm install
npm run dist
```
ملف التثبيت الناتج يكون داخل مجلد `dist`.

## ملاحظات مهمة
- هذا إصدار أولي عملي لإدارة المخزون والمبيعات، وليس نظامًا محاسبيًا مدققًا أو متعدد المستخدمين.
- لا توجد شاشة دخول وصلاحيات حقيقية في هذه النسخة؛ لا تعتبر اسم «مدير المنظومة» في الواجهة نظام مصادقة.
- قارئ الباركود USB الذي يعمل كلوحة مفاتيح يمكن استخدامه في حقل الباركود عند إضافة/تعديل الصنف. دعم أجهزة البلوتوث أو الطباعة الحرارية يحتاج إلى اختبار على الجهاز والطابعة الفعليين.
- النسخ الاحتياطي والاستعادة يجب اختبارهُما قبل استخدام بيانات تجارية مهمة. احتفظ بنسخ متعددة على وسيط خارجي.
- يعتمد هذا المشروع على واجهة `node:sqlite` المتوفرة في إصدارات Node/Electron الحديثة. إذا ظهر خطأ متعلق بها عند التشغيل، أرسل نص الخطأ كاملًا لتحديد توافق نسخة Electron.
- الخط العربي من Cairo قد يحتاج إلى اتصال أول مرة إذا لم يكن الخط محفوظًا محليًا؛ سيستخدم التطبيق خطوط النظام البديلة عند عدم توفره.


## الحسابات وتسجيل الدخول
- عند أول تشغيل ستظهر شاشة إنشاء حساب المدير؛ لا توجد كلمة مرور افتراضية.
- أنشئ اسم مستخدم إنجليزيًا وكلمة مرور لا تقل عن 8 أحرف.
- بعد الدخول، يستطيع المدير فتح (حسابات المستخدمين) وإنشاء حسابات للموظفين أو المديرين وإيقافها.
- كلمات المرور محفوظة كـ hash باستخدام scrypt مع salt، وليست نصًا صريحًا.
- تسجيل الدخول محلي على هذا الجهاز، وليس نظام حسابات سحابيًا.


## قارئ الباركود
- يدعم قارئات الباركود USB التي تعمل كلوحة مفاتيح (Keyboard Wedge) وترسل Enter بعد قراءة الرمز.
- أضف رقم الباركود للصنف من شاشة الأصناف، ثم افتح فاتورة جديدة وامسح الرمز في خانة «قراءة الباركود». سيُضاف الصنف تلقائيًا إذا كان الرمز مسجلًا والكمية متوفرة.
- لا يحتاج القارئ إلى تعريف خاص غالبًا؛ جرّبه أولًا في المفكرة للتأكد أنه يكتب الرمز وينهيه بـ Enter.

## تشغيل نسخة سطح المكتب وإنشاء المثبّت
هذا مشروع Electron لسطح المكتب، وليس موقعًا فقط. لتشغيله من مجلد المشروع على Windows شغّل `تشغيل_المشروع.bat` أو نفّذ `npm install` ثم `npm start`. لإنشاء ملف تثبيت Windows بصيغة EXE نفّذ `npm run dist` بعد تثبيت الحزم. ينتج المثبّت داخل مجلد `dist`، ويمكنه إنشاء اختصار على سطح المكتب وقائمة ابدأ.

## مردودات المبيعات والبيع الآجل
- أضيفت صفحة «مردودات المبيعات» من القائمة الجانبية.
- لتسجيل مردود: افتح الصفحة، اختر «تسجيل مردود»، أدخل رقم فاتورة البيع، وحمّل الأصناف، ثم اختر الصنف والكمية والسبب إن وجد.
- عند حفظ المردود، تُعاد الكمية تلقائيًا إلى المخزون، ولا يسمح النظام بإرجاع كمية تتجاوز الكمية المتبقية من الصنف في الفاتورة الأصلية.
- البيع الآجل موجود ضمن نوع البيع في فاتورة المبيعات؛ اترك المبلغ المدفوع صفرًا لتسجيل كامل المبلغ كرصيد مستحق، أو أدخل مبلغًا جزئيًا للتحصيل الجزئي.
- اسم الزبون اختياري في فاتورة البيع؛ عند تركه فارغًا تُسجّل الفاتورة باسم «زبون نقدي».
